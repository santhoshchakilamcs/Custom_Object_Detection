# Custom_Object_Detection

Do run the code testingimage_video.ipynb code inside the object_detection.ipynb file

## Workflow

This repo follows a Google Colab workflow, as described in the original README and the linked reference post. Run the testing image/video notebook code inside the object detection notebook, following the steps in those notebooks. No files were renamed as part of this documentation-only update, and the notebooks themselves remain the source of record for the model and detection steps used.

## Files

- `object_detection.ipynb` - the main object detection notebook
- `testingimage_video.ipynb` - the testing notebook for images and video, run inside the main notebook
